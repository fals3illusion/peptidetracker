      Database backup (PostgreSQL)
      
    
      Optional. Every change is copied to a PostgreSQL database within a few seconds — your safety net if this container is lost, an easy way to move to a new one (choose “Restore from a backup” when setting up), and what Grafana reads. Your data still lives here; the app works the same with or without it.
      
    
      
    
      
      
      This backup is set in the server’s settings file (PG_URL in /etc/peptidetracker/env), so it’s changed there.
      
      
    
      
    
      
      
      
        Need a database? Run this on your PostgreSQL server
        
      
        
      Also allow this container’s IP in pg_hba.conf and make sure PostgreSQL listens on the network (listen_addresses). Use an empty database, or one this app already backs up to.
      
      
      
      
      
        
      
        
      
        
      
        
      
        
      
      
      
      
      
      
      
      
        
        
        
        
      
      
    
      
  
      
  
      
    
      Grafana dashboard
      
    
      Charts of weight, doses, shots and spending for each person, read from the backup database. Turn on the database backup first.
      
    
        
      
      1. Make a read-only database user for Grafana (on your PostgreSQL server):
        2. 
      
      2. In Grafana: Connections → Data sources → Add → PostgreSQL. Host your-db:5432, database peptidetracker, user grafana_pt, the password above, TLS off (unless you use SSL).
        3. 
      
      3. Import the dashboard: Dashboards → New → Import → upload this file, then pick the data source.
        
        Download dashboard
        4. 
      
      4. Add it to the menu (optional): enter your Grafana address and everyone gets a 📊 Dashboards item in the ⚙ menu that opens their own charts.
        
        
        
        5. 
    
      
    
      The dashboard has a “Person” picker. The read-only user can’t see passwords — Grafana only reads the pt_people and pt_settings views plus the data tables.
